# HoldFast Data Card (v1.0, 2026-08-27)

Companion to `docs/PAPER.md`; provenance in `docs/PLAN.md` (preregistration)
and `docs/DECISIONS.md` (D-007 pipeline, D-012 probes, D-013 nesting,
D-015/D-019 zh arm, A-1 DPO pairs).

## 1. Summary

Synthetic multi-turn math-tutoring dialogues in which the **student's
mathematics is computed by code** (executable misconception rules from
MalruleLib) and only the prose is LLM-rendered, plus frozen single-problem
probe sets and DPO preference pairs. Built to train and evaluate student
simulators that hold an assigned misconception and flip only under targeted
remediation. Domain: middle-school arithmetic/algebra. Languages: English
and Chinese.

## 2. What's in each file

| file | records | contents |
|---|---|---|
| `data/main/scaffolds_16k.jsonl` | 15,849 | code-generated dialogue plans: problem, malrule answer/steps, correct answer/steps, turn plan (no LLM text) |
| `data/main/scaffolds_4k.jsonl` / `_1k.jsonl` | 4,001 / 1,000 | nested deterministic subsets (1k ⊂ 4k ⊂ 16k, per-type) |
| `data/main/rendered_main.jsonl` | 15,298 | EN rendered dialogues (96.5% render yield; nested subsets: 3,923 at 4k, 980 at 1k — 1k cells trained on a 977-dialogue snapshot, see DECISIONS D-027) |
| `data/main/scaffolds_4k_zh.jsonl` / `rendered_zh.jsonl` | 4,001 / 3,867 | zh arm: translated scaffolds + zh renders |
| `data/eval/rendered_eval_{en,zh}.jsonl` | 318 / 319 | held-out eval dialogues (problem texts disjoint from all training pools and probe sets) |
| `data/probes/probes_hold_{en,zh}.jsonl` | 1,992 / 1,759 | frozen misconception probes (SHA-256 pinned at prereg freeze) |
| `data/probes/probes_correct_{en,zh}.jsonl` | 1,000 / 879 | frozen correct-solving probes (H5 guardrail) |
| `data/dpo/pairs_en_4k.jsonl` | 2,134 | balanced DPO pairs (chosen = rendered faithful turn; rejected = code-checked counterfactual) |
| `data/zh/translations.jsonl` | 12,701 | zh translations of unique surface strings, verbatim-math verified |
| `data/audits/`, `data/zh/audit_sample_100.json` | — | archived audit samples ('other'-bucket 30-sample; zh 100-probe translation audit, D-019) |
| `*_failed.jsonl` | — | dropped items with failure reasons (render check-rejections after ≤3 attempts) |

Record schemas (JSONL): rendered dialogues carry
`{dialogue_id, malrule_id, type, lang, turns, attempts, warnings}` with
`type ∈ {hold, flip_targeted, flip_misaligned, control_correct}`; probes carry
`{probe_id, malrule_id, problem_text, malrule_answer, correct_answer, seed,
difficulty, level}`; DPO pairs carry
`{dialogue_id, turn_idx, class ∈ {hold, flip}, messages, chosen, rejected}`.

## 3. How it was made (and what guarantees hold)

1. **Math**: every problem, misconception-consistent wrong answer, step trace,
   and correct solution is generated by MalruleLib's executable malrules
   (pinned commit `8ddedfb`; 100 of 102 malrules — 2 excluded for broken
   automated test suites). No LLM ever computes student math.
2. **Prose**: GLM-5.3 (institutional gateway) renders scaffolds into dialogue
   text under per-turn hard checks — student answers must contain the
   scaffold's code-computed answer; the correct answer must not appear before
   the remediation turn (leak ban, with a statement-containment exemption);
   problem statements verbatim. ≤3 attempts, then the dialogue is dropped
   (drops are logged, not silently discarded).
3. **zh arm**: translations keep all math verbatim (numeric-token multiset +
   variable check on 12,701/12,701 strings; 100/100 audited sample, D-019).
   zh probe sets are the frozen EN sets restricted to language-neutral answers.
4. **Anti-leak splits**: eval problem texts are disjoint from the entire 16k
   training pool and from both probe sets, by construction.
5. **Frozen at preregistration**: probe sets are SHA-256 pinned (PLAN freeze,
   commit `8c1fe4b`); no post-hoc edits.

## 4. Intended uses

Training and evaluating *student simulators* for tutor-training research:
misconception persistence, selective belief revision, sycophancy analysis.
The dialogues contain **deliberately wrong mathematics** (misconception-
consistent answers and reasoning): they are unsuitable as general math SFT
data, as tutoring ground truth, or for any use that treats student turns as
correct solutions.

## 5. Known limitations

- Synthetic dialogues in one tutoring voice (single renderer); no real
  student data, no personally identifiable information anywhere.
- Coverage limited to MalruleLib's middle-school arithmetic/algebra malrules,
  one misconception per dialogue.
- zh probe subset excludes phrase/yes-no answers (language-neutral answers
  only), so zh coverage is a strict subset of EN.
- Render yields are ~96–97%; dropped scaffolds skew slightly toward malrules
  whose answers are hard to phrase without leaking (see `*_failed.jsonl`).
